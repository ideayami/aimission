# 2D Space Shooter (ブラウザシューティングゲーム)

HTML5 Canvas と純粋な JavaScript (外部ライブラリなし) で作られた、レトロフューチャーな宇宙シューティングゲームです。

## 遊び方

1. ブラウザで `index.html` を開きます。
2. スタート画面の「ゲームスタート」ボタン（またはスペースキー）をクリックしてゲームを開始します。
3. 自機を操作して敵を倒し、スコアを稼ぎましょう！
4. **武器パワーアップ**: スコアが **500点** に到達すると、弾が強力な **3方向ワイドショット (3-WAY)** に進化します。
5. **ボス戦**: スコアが **1,000点** に到達すると強力なボスが出現します。ボスを撃破するとステージクリアです。

## 操作方法

- **移動**: 矢印キー (`↑` `↓` `←` `→`) または `W` `A` `S` `D` キー
- **弾の発射**: スペースキー (長押し連射可能)
- **一時停止/再開**: `P` キー または 右上のポーズボタン (❚❚)
- **リスタート**: ゲームオーバー / クリア時にスペースキーまたはリスタートボタンをクリック
- **モバイル対応**: 画面下のタッチボタンで移動・攻撃が可能

## 特徴

- **武器進化システム**: 500点獲得で3方向ワイドショットへパワーアップ。専用エフェクトとサウンドで爽快感アップ。
- **ハイスコア保存 (LocalStorage)**: 獲得した最高得点をブラウザ内に自動記録。ゲームプレイ中やゲームオーバー・クリア画面、スタート画面に常時ハイスコアが表示されます。
- **Web Audio API**: 外部音声ファイルを使わず、ブラウザの音源合成機能で弾発射音・パワーアップ音・爆発音・クリア音をリアルタイム生成します。
- **視覚エフェクト**: スクロールする星空背景や、敵撃破・被弾時の爆発パーティクル演出。
- **難易度スケーリング**: スコアとプレイ時間に応じて敵の出現頻度やスピードが段階的に上昇します。

## 開発環境

- HTML5 / CSS3 / JavaScript (ES6+)
- 外部ライブラリ不使用
